# 📘 Assignment: Debugging and Unit Testing in Python

## 🎯 Objective

Learn how to diagnose bugs in small Python programs and verify behavior with unit tests so your code is more reliable and easier to maintain.

## 📝 Tasks

### 🛠️ Diagnose a Broken Program

#### Description
Review the starter code and find the issues causing incorrect output or runtime errors in a few small functions.

#### Requirements
Completed program should:

- Read the error messages or unexpected outputs carefully
- Identify at least two bugs in the starter code
- Fix the logic so each function produces the correct result
- Add short comments explaining what was wrong and how it was fixed

### 🛠️ Write Unit Tests

#### Description
Create a test file using Python's built-in `unittest` module to check that the corrected functions behave as expected.

#### Requirements
Completed program should:

- Import the corrected functions from the starter file
- Write tests for normal inputs and edge cases
- Use `assertEqual`, `assertTrue`, or `assertRaises` to verify behavior
- Run the tests and confirm they pass successfully

### 🛠️ Improve Code Quality

#### Description
Make the fixed functions easier to read and more robust for real-world use.

#### Requirements
Completed program should:

- Add clear function docstrings or comments where helpful
- Handle edge cases such as empty input or invalid values
- Remove repeated or confusing logic
- Write a brief summary explaining how debugging and testing improved the program
